# ADR-008: Directory on Demand

**Статус:** Принято  
**Дата:** 2026-07-10

## Контекст

Пустые папки создают ложное ощущение структуры и провоцируют «ADR ради идеала».

## Решение

Новая папка в `domain/`, `data/` или `presentation/` появляется **только** когда:

- существует минимум **два** связанных класса, которым нужен общий каталог; **или**
- один самостоятельный архитектурный элемент, оправдывающий отдельную папку.

**Запрещено** создавать каталоги «на вырост».

При добавлении **новой** папки в `domain/` — обязателен **ADR update**.

### Запрет на преждевременные ADR

Новые ADR пишутся **только по факту новой необходимости**, не «на будущее».

## Последствия

- Структура отражает реальный код.
- Архитектура не деградирует от желания предусмотреть всё заранее.
